# Fuzzy Logic Based UAV Landing on an Autonomous Vessel

Generic and sanitized Python framework for determining a UAV approach/landing
angle for landing on a moving autonomous surface vessel using fuzzy logic.

The public implementation demonstrates the software architecture and fuzzy
decision process without reproducing project-specific vehicle parameters,
operational constraints, or unpublished results.

Main modules:
- UAV and vessel kinematics
- Relative-state calculation
- Fuzzy membership functions
- Mamdani-style rule evaluation
- Centroid defuzzification
- Landing-angle command generation
- Generic simulation and visualization
